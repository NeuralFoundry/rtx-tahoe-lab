# Paused research handoff

Development was paused at the user's request on 2026-10-07.

The current source pairing is parent RTXProbe 0.83.1/native owner250 with the
0.253 child/application components. The latest retained lab color experiment
completed 16 native RTX draws and verified native closure, but exact color
comparison still failed. Its finite-sample quantization model is a hypothesis,
not a validated hardware explanation or correction.

Standard Metal enumeration continuation 0.254 was prepared; a positive RTX
enumeration/draw run did not happen. A 32-draw AMD reference comparison was
also prepared but not compiled or executed on the Mac. The final test host
became unavailable after cleanup reboot, so a recovered clean boot was not
confirmed. Future hardware work starts with a fresh observation.

The public repository intentionally excludes raw machine captures and run
receipts. These statements summarize the original lab record and should not
be mistaken for independently verifiable full hardware proof in this release.

Remaining work: color behavior; positive standard enumeration; general shader
compilation and submission; broader Metal operations; presentation/display
integration; and stability. No supported daily-use driver or ETA is promised.
